安装与注册

下载渠道

访问蓝印RPA官网 https://www.lanyinrpa.com/，下载 Windows 客户端安装包[1]。

安装步骤

  1. 下载 Windows 安装 exe。
  2. 双击安装包执行安装。
  3. 安装完成后打开蓝印RPA编辑器。

内置蓝印浏览器

蓝印RPA 自带内置蓝印浏览器（基于 Chromium 内核），开箱即用，无需额外安装浏览器插件，元素拾取与流程执行都在内置浏览器中完成[2]。

注册与登录

  • 社区版免费，无需续期，适合个人学习与中小型场景。
  • 登录账号后进入编辑器主界面。

来源：蓝印官网与官方文档[1][2]。

界面概览

蓝印RPA编辑器主界面分区如下[2]：

  • 左侧：指令列表（可拖拽到流程编辑区）。
  • 中间：流程编辑区（组装指令，搭建流程）。
  • 右侧：指令属性配置区（配置选中指令的参数）。
  • 内置浏览器（元素选择与流程执行）。
  • 变量管理区（查看/管理流程变量）。

与影刀对比：蓝印界面更简洁，指令数量少（仅 16 大类），适合快速上手；影刀功能分区更多、指令更全。

来源：蓝印官方文档[2]。

核心概念

流程 / 应用（Process）

流程是蓝印RPA 的最大容器，一个流程可打包为独立 EXE 分发给他人使用[6]。

指令（Command）

蓝印RPA 共有 16 大类指令：

大类用途
浏览器操作启动/关闭浏览器、标签页管理
鼠标操作单击/双击/拖拽/滚轮
元素操作对网页元素的点击/读取
页面操作前进/后退/刷新/滚动
输入操作填写输入框、模拟键盘
网页设置等待加载、JS 注入
数据过滤与监听抓取列表/表格数据
数据操作变量赋值、JSON 处理
系统操作文件/文件夹/进程
流程控制条件/循环/跳出
等待操作固定/智能等待
Excel 表格读写单元格、工作表
定时操作定时器指令
数据处理字符串/日期/正则
网络操作HTTP 请求
对话框弹窗提示/输入

变量（Variable）

  • 自定义变量：任意类型，根据值自动判断类型。
  • 变量名规则：字母 / 数字 / 下划线 / 中文，首字符非数字。

元素 / xpath 路径

蓝印以 xpath 为主定位网页元素，辅以 css 选择器[3]。

标签页对象

由"启动浏览器"等流程创建的标签页对象，是后续指令操作的目标。

与影刀差异：蓝印无独立"数据表"对象，表格数据通过 Excel 指令直接读写或 JSON 中转；蓝印无桌面 UI 元素拾取（桌面操作仅靠坐标/图像/OCR）。

元素拾取

网页元素拾取步骤

  1. 点击"选择元素"按钮。
  2. 鼠标移到内置浏览器目标元素上。
  3. 元素高亮显示。
  4. 单击鼠标左键完成拾取。
  5. 系统自动生成 xpath填入指令配置框[3]。

校验元素

点击"校验元素"按钮，若 xpath 存在则浏览器高亮该元素，确认拾取正确[4]。

相似元素

通过"获取相似元素个数"配合 For 循环改变"元素顺序"（从 0 开始，-1 表示随机），可批量操作同类元素。

隐藏元素

需鼠标移动才显示的元素，可用快捷键抓取。

蓝印 vs 影刀：蓝印仅支持网页元素拾取（xpath）；影刀支持桌面 + 网页（默认捕获 / XPath / CSS）。

来源：蓝印元素拾取文档[3]、校验元素文档[4]。

搭建第一个流程

目标：用蓝印自动打开百度搜索关键词。

  1. 加载URL：拖拽"加载URL"指令 → 输入百度地址 https://www.baidu.com。
  2. 填写输入框：拖拽"填写输入框"指令 → 选择元素 → 拾取百度搜索框 → 输入关键词。
  3. 点击元素：拖拽"点击元素"指令 → 拾取"百度一下"搜索按钮。
  4. 运行流程：点运行，蓝印自动执行：打开百度 → 输入 → 点击搜索。

与影刀对比：蓝印步骤类似但指令名不同——蓝印无"打开新网页"指令，而是用"加载URL"在当前标签页打开地址。

调试与运行

蓝印调试能力

  • 单步调试：逐条指令执行，便于定位问题。
  • 运行日志查看：底部日志栏实时显示执行结果与报错。

与影刀差异：蓝印调试功能较简洁，无断点功能（影刀支持断点 + 变量面板）。

来源：蓝印官方文档[2]。

定时调度与EXE打包

定时器指令

定时器指令置于流程内，触发后异步执行，主流程继续向下运行。

定时执行（应用级）

标准版起支持应用级定时执行（标准版 ¥35/月）[5]。

EXE 打包分发

  • 专业版（¥78/月）起可打包独立 EXE 分发[6]。
  • 创业版可自定义界面 / 图标 / 授权。

离线内网部署

  • 社区版：离线授权 30 次。
  • 专业版：离线授权 1 台[5]。

API 接口

专业版起提供 webRPA 接口，可被外部系统调用。

IM Agent

专业版起，可在钉钉 / 飞书 / 企微 / 个人微信里 @机器人控制流程执行。

与影刀差异：蓝印无云端控制台，调度模式为单机 + 定时 + API + IM Agent；影刀有云端控制台与机器人集中管理。

来源：蓝印VIP方案[5]、打包教程[6]、博客园实测[7]。

常见问题 FAQ

Q1：元素拾取不到怎么办？

检查是否使用内置蓝印浏览器（非系统浏览器）。元素拾取依赖内置浏览器的 Chromium 环境。

Q2：xpath 失效了？

网页结构变化导致 xpath 失效。解决：重新拾取元素，或改用更稳定的 xpath（优先 id/name 类属性，避免过长的绝对路径）。

Q3：流程运行报错怎么定位？

查看运行日志定位失败指令，根据报错信息修正对应配置或元素。

Q4：定时执行不可用？

社区版不支持定时，需标准版起（¥35/月）[5]。

Q5：EXE 打包不可用？

社区版不支持 EXE 打包，需专业版起（¥78/月）[6]。
