安装与注册

系统要求

  • 操作系统：Windows 7 及以上（推荐 Win10/11 64位）、macOS 10.12+、信创系统。跨平台是影刀核心优势之一[1]。
  • 内存：至少 4GB RAM（8GB+ 推荐）；硬盘至少 2GB 可用空间（安装包约 600MB）。

下载与安装

  1. 访问影刀官网 yingdao.com/client-download，根据系统选对应版本下载。
  2. 双击安装包（Windows 下形如 ShadowBot-5.30.37-x64.exe），UAC 提示点"是"。
  3. 选择安装位置（建议非系统盘），依次"下一步"接受许可协议至安装完成（约 1-3 分钟）。
  4. 桌面出现影刀RPA 快捷方式，启动即可。建议安装前关闭杀毒软件避免误拦截[1]。

注册与登录

  1. 首次启动点"注册"，输入手机号获取验证码，设置密码完成注册。
  2. 用注册账号登录进入主界面，新用户通常享 30 天免费体验期[2]。

浏览器插件安装（网页自动化必需）

影刀网页自动化需配合浏览器插件，支持 Chrome 和 Edge：

  • Chrome/Edge：客户端 → 右上角头像 → "工具" → "自动化插件" → 选对应浏览器 → "安装插件" → 重启浏览器 → 在 chrome://extensions/ 确认开发者模式与影刀插件已开启[1]。
  • 影刀浏览器：影刀自带，开箱即用、静默运行、环境独立，云端运行时推荐使用影刀浏览器（云端无本地 Chrome 配置）[3]。

常见插件故障：装失败先完全退出浏览器重试；装后无法用检查浏览器版本是否过旧；"打开网页"能打开但元素指令全报"找不到元素"，多半是插件没装/未启用——这是新手最高频踩坑。

影刀客户端由两大核心界面组成：综合管理界面（应用/任务管理）与应用开发界面（流程开发）[4]。

应用开发界面（核心编辑区）

开发界面分 5 个功能区，简记"左侧指令库 → 中间画布 → 右侧属性面板，底部日志/变量面板，右下角全局变量入口"[4][5]：

右下角全局变量入口：全局变量按钮在右下角，需点开小箭头才显示，新手常找不到。Python 块引用全局变量必须用 package.variables['变量名'] 格式，直接用变量名会报错[5]。

核心概念

流程（应用 / Process）

影刀采用积木式流程搭建，通过"拖、拉、拽"实现。一条流程由多条指令按逻辑堆叠构成。一个"应用"可包含主流程和多个子流程（可视化子流程），子流程可被调用以模块化设计；还支持新建 Python 模块调用影刀自动化接口开发高级流程[6]。

指令 / 组件（Command）

一条指令 = 一个动作。指令构成四要素：对象（如网页对象）+ 元素（如某按钮）+ 操作（如点击）+ 结果（保存到变量）。双击或拖动指令会弹出配置界面，配置完毕的指令出现在流程编排区[6]。

魔法指令是影刀特色功能，基于大语言模型 AI Coding，用户描述需求即可自动生成流程指令（详见影刀结合AI）。

变量（Variable）

变量是"给数据起一个名字"，方便后续流程直呼其名调用[5][7]：

  • 局部变量：指令输出保存的变量，在当前流程内使用。
  • 全局变量：可被所有流程统一使用。注意：全局变量必须先在指令输出部分出现且影刀运行到该指令时才生效（执行到前是默认值，执行后变为新值）。
类型说明取值方式
字符串文本直接引用
数字整数/小数直接引用
列表有序集合索引 list[0]
字典键值对键 dict['key']
JSONHTTP 接口返回Python 块 json.loads()

元素拾取（元素捕获）

元素定位是 RPA 最核心技能。影刀提供三种定位方式[8]：

  1. 元素捕获（默认）：影刀自动记录元素路径+限制条件。
  2. CSS 选择器：CSS 语法定位，性能好，适合简单属性匹配。
  3. XPath 选择器：功能最强，支持模糊匹配（contains）、上下文定位、层级定位等。

元素捕获操作步骤

  1. 点击"捕获新元素"（快捷键 Alt+Ctrl+P）。
  2. 鼠标悬浮到目标元素，等待红框包围。
  3. 按住 Ctrl 键单击鼠标完成捕获。
  4. 系统自动生成元素选择器，保存到元素库。

元素捕获原理

影刀记录元素路径（如 div > div > span）和限制条件（如 id="submit"、class="btn-primary"）。页面结构变 → 路径可能失效；元素属性变 → 限制条件失效[8]。

提升稳定性的关键：双击进入元素编辑器，只勾选稳定属性（id/name），取消不稳定属性（动态 class、会变的 innerText）；动态属性用 contains 模糊匹配；用"等待元素出现"指令替代固定等待。

搭建第一个流程

以"自动打开百度搜索关键词"为例[6][2]：

  1. 新建应用：打开影刀 → "新建" → 创建 PC 自动化应用 → 进入开发界面。
  2. 添加"打开网页"指令：左侧"网页自动化" → 拖"打开网页"到画布 → 右侧配置浏览器选 Chrome/影刀浏览器，网址填 https://www.baidu.com → 网页对象保存到变量 web_page。
  3. 添加"填写输入框(web)"：拖指令 → 元素编辑器中捕获百度搜索框（悬浮红框后 Ctrl+单击）→ 输入"影刀RPA"。
  4. 添加"点击元素(web)"：拖指令 → 捕获百度首页"百度一下"按钮。
  5. 运行：点顶部"运行"，影刀自动执行：打开百度 → 输入 → 点击搜索。

进阶：加"获取元素文本内容(web)"指令获取第一条搜索结果文本，赋值给变量，再用"打印输出"指令在底部运行日志栏显示。指令添加支持快捷键 Ctrl+Shift+P；流程录制功能可录制操作自动生成流程，进一步降低门槛。

调试与运行

只有在编辑器中打开应用时才能调试；计划任务、API 调度、后台调度或应用外右键运行时不能调试[9]。

断点

  • 打断点：鼠标移到指令行号后空白处点击，指令前出现橙色圆点即为断点。
  • 执行到断点自动暂停，暂停时该指令尚未执行，可在下方调试变量面板查看所有变量实时值和类型。

单步调试与继续

  • 继续：执行到下一个断点（含循环中再次执行到同一断点）或结束。
  • 单步调试：每次点击多执行一条指令。

调试一般步骤

  1. 运行应用，定位报错指令。
  2. 在报错指令前打断点，再次运行，在变量面板查看实时值（如发现 Excel 对象变量为 None，说明缺少"启动 Excel/获取激活 Excel"赋值）。
  3. 修复后取消断点再运行，遇到新报错重复上述过程。
  4. 循环中用"继续"逐轮观察变量，发现异常值（如空行 [None]）后修正数据。

运行日志

编辑器底部"运行日志"栏实时显示执行结果。本地日志文件路径：Win+R 输入 %localappdata%\ShadowBot\log 打开日志文件夹，按时间倒序查看最新日志文件[10]。排查连续失败时，靠日志时间线还原每轮卡在哪一步。

定时调度与机器人管理

定时触发器配置

  1. 先将应用发版（发布到云端）——触发器仅支持已发版或已获取的应用[11]。
  2. 客户端顶部菜单栏 → "触发器" → "新建" → "定时触发器"。
  3. 配置：名称、应用、频率（每分/每时/每天/每周/每月，或高级 Crontab）、定时结束时间、是否排队执行、运行超时强制结束分钟数。
  4. 确定后启用，在运行日志中查看触发器执行记录[12]。

触发器四种类型

触发器触发方式
定时触发器按设定周期（含 Crontab 高级表达式）定时运行
文件触发器监控文件变化，如新文件出现时自动处理
热键触发器键盘快捷键手动启动任务
邮件触发器收到特定邮件时触发自动化流程

注意：触发器只能执行已发版或已获取的应用；含交互对话框的应用定时执行会卡住——定时器无人点击确认会一直等待，需把对话框内容写死到程序中。

本地 vs 云端选型

场景推荐方案原因
自己日常用本地免费、灵活、随时调整
给客户交付云端不依赖客户电脑、7×24 运行
企业内部使用本地服务器数据不出内网、安全性高
高频定时任务云端专业调度、执行记录完整
手机自动化本地云端不支持 ADB 连接

常见问题 FAQ

Q1：流程运行报错"找不到目标元素"怎么办？

最常见问题。原因：页面结构/属性变化导致捕获的路径或限制条件失效。解决：①双击进入元素编辑器，只勾选稳定属性（id/name），取消不稳定属性；②改用 XPath/CSS 手写定位；③用 contains 模糊匹配动态属性；④加"等待元素出现"指令替代固定等待[13]。

Q2：循环操作时报"未找到指定ID的元素"？

循环中网页刷新，导致刷新前捕获的元素失效。解决：循环内每次重新获取元素，或用更稳定的 XPath 定位[14]。

Q3：云端运行结果和本地不一致？

浏览器版本差异、网络延迟、云端无本地 Cookie/登录态。解决：云端用影刀浏览器；等待时间适当增加；把登录子流程放主流程最前（云端每次都是全新环境）[3]。

Q4：定时触发器执行时流程卡住不动？

应用含交互对话框，定时器无人点击确认会一直等待。解决：把对话框内容写死到程序中避免交互[12]。

Q5：本地路径在云端报错 / Excel 操作失败？

云端无本地 C:\Users\xxx\ 路径；云端默认不装 Excel。解决：改用相对路径或"获取临时文件夹路径"指令；Excel 操作改用 CSV 导出或 Python 的 openpyxl[3]。

Q6：免费版能否打包 EXE 给别人用 / 商用？

社区版/免费版不能打包 EXE、无授权体系、不可商用交付，仅供个人学习。需打包交付或商用须选创业版/企业版[15]。

Q7：在 Python 块里引用全局变量报错？

必须用 package.variables['变量名'] 格式引用，直接用变量名会报错。主流程参数值超过 4000 字节会丢失，别把大段 JSON 塞默认值[3]。

踩坑速查表

报错/现象原因解决方法
机器人离线网络断开或电脑休眠电脑不关机不休眠，保持网络连接
应用发布失败流程语法错误或依赖缺失本地完整跑一遍确认不报错再发布

ends-with 不生效Chrome 的 XPath 1.0 不支持用 contains 代替
元素捕获一直是全屏客户端捕获偏移重启影刀客户端通常可解决
