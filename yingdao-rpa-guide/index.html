影刀RPA 是什么

影刀RPA 是杭州分叉智能科技有限公司研发的一款 RPA（机器人流程自动化）软件，又称"数字化劳动力"[1]。它通过模拟人与计算机的交互行为（鼠标点击、键盘输入、信息读取等），自动执行重复性、机械式工作，核心理念是无代码可视化编程——用户无需编程基础，通过拖拽式操作即可构建自动化流程[2]。

影刀支持跨平台自动化覆盖：桌面软件、Web 网页、手机 App 均可操作，支持多台手机同时控制[1]。可将任务执行速度提升 3-5 倍，错误率接近 0，支持 7×24 小时不间断运行。

一句话定位：影刀RPA 是一款"低代码、好上手"的国产 RPA，在国内电商、财务、运营自动化领域使用广泛。它把重复规则化的人工操作交给"数字员工"，让人聚焦创造性工作。

适用场景

凡是重复、规则明确、跨系统搬运的桌面操作，都是 RPA 的主场。影刀的典型应用：

数据录入核对

跨系统数据搬运、单据录入、库存核对

报表生成

定时采集多源数据、汇总计算、自动发送

网页信息采集

电商比价、舆情监控、招聘数据统计

电商运营

商品上下架、价格监控、订单处理

财务单据处理

发票识别、银行流水导入、应收应付对账

ERP/SAP 操作

采购订单、销售订单、主数据维护

版本与授权模式

影刀采用多版本 + 授权机器人数量的商业模式。版本命名较易混淆（"个人高级版"实为免费版），具体以官网公示为准[3][4]：

版本定位关键限制能否打包EXE/商用
社区版/个人高级版个人学习、体验按月免费额度；功能较全但无独立授权不能打包 EXE、不可商用
创业版小团队/个人开发者询价制，支持一定商用，限单人使用可打包交付
企业版/专业版企业级部署云端调度、多机器人管理、API调度、控制台完整授权与交付

授权要点：本地机器人 = 企业高级账号登录客户端开启"调度模式"即变成受控制台调度的影刀机器人；云端调度 = 控制台发布应用+配置定时任务+选择执行机器人，实现 7×24 运行不依赖本地开机[5]。

核心概念速览

影刀围绕以下核心概念组织，详见基础使用指南：

概念说明
应用 (App)最大容器，一个应用 = 一条可运行流程，含主流程+子流程+Python模块
指令 (Command)流程每一步，四要素：对象+元素+操作+结果变量
变量局部变量（流程内）/ 全局变量（跨流程）；数字/字符串/列表/字典
元素拾取定位网页/桌面控件，默认捕获 / XPath / CSS 三种方式
数据表内置 Excel 二维表，采集结果中转站
触发器定时/文件/热键/邮件 四种触发应用执行的方式
机器人 (Bot)本地机器人（开启调度模式）/ 云端调度机器人
